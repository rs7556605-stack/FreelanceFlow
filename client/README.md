FREELANCEFLOW
A Project Management Tool for Freelancers

1. Project Name
FreelanceFlow

2. Project Description
FreelanceFlow is a web-based project management and business management
application designed to help freelancers manage clients, projects, tasks,
time tracking, invoices, and financial activities from a single platform.

3. Technologies Used
Frontend:
- React.js
- JavaScript
- HTML5
- CSS3
- Tailwind CSS

Backend:
- Node.js
- Express.js
- REST API
- JWT Authentication

Database:
- MongoDB
- Mongoose

4. Main Features
- User Registration and Login
- JWT Authentication
- Protected Routes
- Forgot Password
- OTP Verification
- Password Reset
- Client Management
- Project Management
- Task Management
- Time Tracking
- Time Logs
- Invoice Management
- PDF Invoice Generation
- Revenue Analytics
- Upcoming Deadlines
- Contact Form
- Email Integration

- Responsive UI
